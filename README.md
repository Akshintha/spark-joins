# spark-joins

This repository demonstrates the different types of joins available in PySpark.

## Project Objective

In this project, I learned how to:

- Create DataFrames
- Join multiple DataFrames
- Understand different join types
- Work with common PySpark join operations
- Analyze data using joins

---

## Join Types Covered

- Inner Join
- Left Join
- Right Join
- Full Outer Join
- Cross Join
- Self Join

---

## Technologies Used

- Python
- PySpark
- Apache Spark

---

## Learning Outcome

This project helped me understand how different join operations work in PySpark and when to use each join type while combining data from multiple DataFrames.
